# WSE-Bench v1.0.0 — First Open-Source Release

## TL;DR

- **156-task reading-comprehension + reasoning + citation-verification benchmark**
  across 14 cohorts.
- **Per-round evolution ledger** (35 entries, r17 → r28) with strict promotion
  gates (paired McNemar p<0.05 *and* cluster bootstrap CI lower bound >0).
- **Reproducible** under one generation protocol
  (Qwen2.5-3B-Instruct 4-bit NF4, T=0.7, top_p=0.9, max_new=128,
  repetition_penalty=1.05, do_sample=True, `torch.manual_seed(seed)` per call).

## Headline result

The **#33 entry** in `assets/evolution_ledger.json`: applying a single
grounding-prefix intervention to Qwen2.5-3B-Instruct over 16 RC tasks
(T103-T118) at K=5 seeds yields a **+18.8%** absolute pass-rate delta with
exact paired McNemar *p* = 0.0315. The bootstrap CI at n=80 brushed the
zero boundary; subsequent larger-n replications (r28 large-n, K=15) push
the effect to **+20.4%** over 32 tasks × K=15 (n = 480 pairs) with CI
**[+11.9%, +29.0%]** — strictly above zero.

## Honest scope & limits

- **Single-model evidence**: Qwen2.5-3B-Instruct is the only model for
  which the #33 evidence is closed. Multi-model replication (Llama-3.1-8B,
  Mistral-7B) is built (`_r28_multimodel.py`) but requires compute beyond
  the 6 GB-VRAM / 16 GB-RAM development machine. We mark this row
  explicitly "未消" in `EFFECT_SIZE_CI_POWER_r28_FINAL.md` §4.
- **Closed-source probes** (T029-T031 in the manifest) are kept as
  `REPLACE_WITH_YOUR_*` placeholders so anyone with a private/local KB can
  instantiate the closed-book probe without inheriting the original
  author's paths or numbers. The probe's measurement role is preserved.
- **Power curve for paired McNemar (Δ ≈ +20%)**:
  - n = 80 (#33 baseline): post-hoc power ≈ 0.59; CI brushes zero.
  - n = 240 (r28 OLD16 replication): post-hoc power ≈ 0.92;
    CI [+6.3%, +33.8%].
  - n = 480 (r28 FULL): post-hoc power > 0.99; CI [+11.9%, +29.0%].
- **Audit bug-fix history**: the v1 leakage heuristic in
  `audit_contamination.py` had a 36% false-positive rate on RC-cohort tasks
  due to undercounting embedded-source markers; v2 in
  `_audit_contamination_r28.py` narrows detection to genuinely-leaking
  prompts.

## Reproducing the headline result

```bash
# Install
python -m venv .venv && source .venv/bin/activate
pip install torch==2.5.1 transformers==4.57.3 bitsandbytes scipy

# Download Qwen2.5-3B-Instruct (~6 GB)
python _download_qwen3b.py --out F:/hf_cache/models/Qwen--Qwen2.5-3B-Instruct

# Run both arms (paired-baseline ablation, K=5, 16 tasks)
python ._ablation_30q_k5.py            # base arm (no prefix)
python _r27_strict_ablation.py         # cand arm (with grounding prefix)

# Aggregate statistics
python _r28_effectsize_analysis.py     # McNemar + Cohen's g + CI
python _r28_bootstrap_ci.py            # cluster bootstrap (B=20000)
```

Note: every script uses `ROOT = Path(r'__WSE_REPO_ROOT__')` as a placeholder
for your local clone path. Replace with your actual path or set the
`WSE_REPO_ROOT` env var and adapt the `ROOT` line.

## Security & privacy posture

- MIT license.
- No model weights in the repo; no per-seed model outputs in the repo.
- A sensitive-residue scanner (`_audit_sensitive_residue.py`) is wired into
  GitHub Actions (`.github/workflows/security-audit.yml`) and fails any PR
  that re-introduces real names, private paths, private numbers, or personal
  email/IP fragments.
- A manifest-tampering guard verifies on every CI run that T029-T031 still
  carry the `REPLACE_WITH_YOUR_*` placeholders.

## What we explicitly do *not* ship

- The author's private session notes (`HANDOFF_NEW_CONVERSATION.md`,
  `self-evolution-overview.md`, etc.).
- Per-seed model outputs (`submissions_*.json`, `blind_prompts.json`,
  `prompts_*.json`) — kept locally, regenerated by the reproduction
  scripts on any host.
- One-off paper-discovery helpers (`_batch*_papers.py`) that hard-code the
  author's private KB paths.
